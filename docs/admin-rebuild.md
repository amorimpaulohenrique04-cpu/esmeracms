## Stage 0 — Security and baseline

Stage 0 establishes a reproducible engineering baseline before structural admin changes.

### Runtime baseline

- Node engine: `>=20.9.0`
- Local recommended Node LTS: Node 24 (`.nvmrc`)
- Next.js: `16.2.11`
- `eslint-config-next`: `16.2.11`
- Payload packages: remain on `3.86.0`
- React / React DOM: remain on `19.2.6`

### Required release gate

Run:

```bash
pnpm install --frozen-lockfile
pnpm validate:release
```

`validate:release` includes generated Payload types/import map, typecheck, lint with zero warnings, integration tests, production build and Playwright E2E.

### CI Stage 0 contract

The Stage 0 workflow must:

1. start a disposable PostgreSQL service;
2. use Node 24 and pnpm;
3. refresh and commit `pnpm-lock.yaml` only when dependency metadata changed;
4. install dependencies with the resulting lockfile;
5. install Playwright Chromium;
6. run `pnpm validate:release`;
7. run `pnpm baseline:capture`;
8. upload baseline screenshots and Playwright diagnostics as artifacts.

The reconstruction must not advance to Stage 1 until the validation job is green or any failure is explicitly diagnosed and fixed.
